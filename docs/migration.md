# Migration boundaries

This foundation milestone creates the Devcraft Toolkit catalog, validation tools, and three available skills. It does not migrate another repository or replace an existing installation.

Comprehensive Code Review remains an independent project and has no catalog entry, dependency, route, test subtree, or migration task here. Reconsider any integration only after its owner selects a stable version and authorizes a separate design. Do not archive its source repository as part of this milestone.

The other fourteen catalog entries are planned. They have no discoverable `SKILL.md` placeholders and are not emulated by the entry skill. Each later capability needs its own design, implementation, and evidence before its catalog status changes.

Platform-specific business integrations, plugin packaging, automated installation, CI distribution, and release automation are also deferred. No license is selected in this repository by this milestone.
