# Devcraft Toolkit v0.1.0-preview.7

Experimental hosted PR/MR management and explicit ordinary promotion, prepared in PR #9 with the versioned changelog and release documentation in the same merge. Tag/assets must target that exact merge commit; no later preparation commit on main is needed.

Sixteen skills are available and only git-publish-work remains planned. Native plugins/Powers and complete skill sets expose the selected revision's canonical resources; installation scope/lifecycle differ by client. Crew uses its importer and existing agent without a toolkit template or App.

See the [changelog](../../CHANGELOG.md), [installation](../installation.md) and [compatibility evidence](../compatibility.md).

## Included capabilities

`git-manage-pull-request` defaults to offline proposal and supports explicit hosted observation, one requested creation or selected title/body patch. Canonical host/account/project/fork identity, complete duplicate search, template/change coverage, concurrent fields and interpreted GitLab text effects remain gates. An existing exact open request on create is no_op without an inferred edit. No lifecycle/approval/reviewer mutation or push follows.

`git-promote` defaults to offline assessment and may execute one expressly requested normal merge of an existing request. It requires current scoped policy/review/check gates, compatible known mergeability/effects and a server-enforced full source OID. Strict unsupported target conditions, queues/trains, forced squash/rebase and unavoidable source cleanup block execution. Post-reads distinguish actual immutable merge provenance, pending work and mutable target containment; no retry, rollback, branch deletion, release or deployment is inferred.

Management requires context only (two-folder closure); promotion adds management/context (three folders). The entry retains its base and adds optional ownership-aware routes. Complete hosted selectors need no local Git scan, clean worktree or commit identity. The suite retains all fourteen preview.6 skills; earlier tags preserve their inventories.

## Downloads and integrity

Download `devcraft-toolkit-v0.1.0-preview.7.zip` and `SHA256SUMS.txt` from [the GitHub release](https://github.com/omarfrancodev/devcraft-toolkit/releases/tag/v0.1.0-preview.7). Verify the ZIP SHA-256 before extraction with `Get-FileHash -Algorithm SHA256` or `sha256sum`.

The ZIP contains the exact tagged merge tree: skills, manifests, documentation and external tests. It excludes Git internals, ignored worktrees, caches, temporary files and generated distributions. Consumers normally use remote installation; manual copies require complete folders and dependencies.
