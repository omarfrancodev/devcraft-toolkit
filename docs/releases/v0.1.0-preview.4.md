# Devcraft Toolkit v0.1.0-preview.4

Experimental exact staging and local commit construction, prepared in PR #6 with its changelog and release documentation in the same merge. The GitHub release tag must target that merge commit; no follow-up release-preparation commit on main is required.

Eleven skills are available and six catalog capabilities remain planned. Native plugins/Powers and complete skill sets expose the same canonical resources; delivery, scope and lifecycle differ by client. Crew uses its own importer and existing agent, without a toolkit template or App.

See the [changelog](../../CHANGELOG.md), [installation overview](../installation.md) and [compatibility evidence](../compatibility.md).

## Included capabilities

`git-stage-changes` performs explicitly authorized exact index transformations, verifies the complete target manifest and preserves excluded index/worktree content. `git-commit-builder` composes planning, staging, safety, local validation and progress capabilities to create explicitly requested normal commits.

Fresh preflight, effective identity, scoped validation and hook/helper inspection gate writes. Unknown or unauthorized index-write hook effects block before mutation; hooks are never bypassed. Failures report actual commits and residual state without automatic rollback. A proposal, installation or ready preflight grants no write permission. Branch creation, history rewriting and remote publication are outside these contracts.

The complete suite includes the nine earlier capabilities plus these two skills. Selected installations need explicit dependency closures: staging requires four skills; standalone commit construction requires nine. Preview.3 remains a nine-skill snapshot, and preview.2 retains seven.

## Downloads and integrity

Download `devcraft-toolkit-v0.1.0-preview.4.zip` and `SHA256SUMS.txt` from [the GitHub release](https://github.com/omarfrancodev/devcraft-toolkit/releases/tag/v0.1.0-preview.4).
Verify the ZIP's SHA-256 against that file before extraction. The ZIP is a source/package archive of the exact tagged merge commit, including canonical skills, manifests, docs and external tests. It excludes Git internals, ignored worktrees, caches, temporary files and generated distributions.

PowerShell `Get-FileHash -Algorithm SHA256` or a platform's `sha256sum` can calculate the download digest. Consumers normally use remote installation routes; manual copies must include complete skill folders and every required dependency.

## Publication procedure

Prepare the versioned changelog, manifest versions and consumer docs on the PR branch. Verify the tree, then merge PR #6 with an expected-head guard. Build the ZIP from that exact merge revision, verify every entry against Git blobs, run package checks, upload and verify the draft prerelease assets, and publish the tag/assets at that same revision. Keep previous release assets and tags unchanged. No automatic installer, release workflow, license or marketplace submission is introduced.

Use command-local `-c core.autocrlf=false -c core.eol=lf` with `git archive` so a Windows checkout's global line-ending preferences cannot alter packaged blob bytes. Verify every archived file against the selected Git tree rather than accepting normalized-but-different content. This does not change local or global Git configuration.
