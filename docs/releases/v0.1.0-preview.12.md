requested local Markdown output. Each new report asks for its layout. Daily
tables retain dates without matching commits, respect the selected timezone

## Validation and save limits

The default save requires a host guarantee preventing additional hard links
through the last content write, for new reports and replacements. Native
Windows handle sharing and a single-link check do not supply that guarantee on
NTFS. Without it, default output returns a failure before directory or file
creation or content changes. A verified volume without hard-link support, or a
host operation with enforced isolation, can satisfy this requirement. The
successful guarded-save path was evaluated with supplied facts; native plugin
activation and a successful save with additional hard-link isolation remain
unverified.

Explicit user-selected paths retain the report writer's existing one-file
contract and existing-parent requirement. File intent, format choice,
replacement authorization, safe execution and matching readback remain required.

[Release preparation](../../tests/integration/distribution/evaluations/2026-11-07-preview12-release/preparation.md)
