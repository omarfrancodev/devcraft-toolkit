# Devcraft Toolkit v0.1.0-preview.11

Experimental issue authoring and requested subtask decomposition in a suite of
twenty independently packaged capabilities. Issue Builder covers bugs, improvements
and new features, faithful selected revisions and explicit parent decomposition.
It preserves confirmed scope and distinguishes reported evidence, open decisions
and optional advice, returning text without executing or publishing the work.

PR #14 contains the implementation, changelog and all release preparation before
its merge. The tag and assets target that exact merge, with no later preparation
commit on main. Preview.10 and earlier tags retain their original inventories.

## Validation boundaries

[Preparation evidence](../../tests/integration/distribution/evaluations/2026-11-03-preview11-release/preparation.md)
records the actual fresh suite, validators, metadata parsing and source review.
The PR review found no confirmed source defects but reported 29 Git fixture
setup errors caused by long temporary paths in its environment. That run is not
called a pass. Fresh validation uses the selected local feature checkout; source
logs retain outcomes and sanitize personal path prefixes. Windows symlink
privilege omissions remain separate from passing tests.

Behavioral applications, isolated folder-copy validation, metadata parsing and
native activation are separate evidence. Native dispatch, unrestricted-tool
behavior and per-client lifecycle remain unverified. Synthetic samples do not
establish statistical reliability. No tracker integration, installer, license,
release automation or deferred code-review integration is added.

## Publication checks

All source preparation remains in PR #14. Require fresh target rules/reviews/checks
and a server-enforced full source SHA for ordinary merge. Require candidate and
merge tree equality. Build the archive from the exact merge with command-local
LF settings; compare every member with its Git blob, compile Python sources
without execution, run extracted validators and check all twenty sidecars.
Upload ZIP and checksum to a draft prerelease, independently download and verify
both assets, then publish and verify the tag target and actual publication date
in America/Mexico_City. Preserve older releases/tags. Final receipts belong to
release metadata and temporary local artifacts; remove temporary packaging after
verified publication, without a post-merge source-preparation commit.
